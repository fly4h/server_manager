# 免费构建资源调研（用于构建 server-manager 镜像）

调研时间：2026-10-09。云厂商/CI 平台的免费政策变动频繁，**额度数字以各家控制台当天页面为准**，本文给出的是当时可查到的口径与选型判断。

背景：本机（Windows Server 2022 云主机）无法运行 Docker —— 固件层未启用虚拟化（`VirtualizationFirmwareEnabled=False`）、无 Hyper-V 功能包、无 docker CLI，所以 `docker build` 必须借外部算力。

## 四、国内构建的两个必备配置

### 1. Docker 镜像加速器（拉 golang/node/alpine 基础镜像）

实测口径（2026-09，各来源略有出入，**先验证再写入 daemon.json**）：

| 地址 | 状态 |
| --- | --- |
| `https://<你的ID>.mirror.aliyuncs.com` | 阿里云专属地址，**最稳**，需注册后在「容器镜像服务 → 镜像加速器」拿到 |
| `https://docker.m.daocloud.io` | 可用，速度较快 |
| `https://mirror.baidubce.com` | 可用，速度中等 |
| `https://mirror.ccs.tencentyun.com` | 腾讯云内网好用，公网偶发超时 |
| `https://docker.mirrors.ustc.edu.cn` | ⚠️ 说法不一：有来源称仍可用、有来源称已停止服务 |
| `http://hub-mirror.c.163.com` | 时好时坏，且仅 HTTP，需要额外放行 |

验证一条命令就够（返回 **401** 说明源活着，超时/403/404 就是挂了）：

```bash
curl -I https://docker.mirrors.ustc.edu.cn/v2/
```

建议 `daemon.json` 里最多放 3 个，放多了会因超时等待反而变慢。

### 2. 多架构（arm64）真的需要吗

- `docker buildx` 跨架构靠 QEMU 模拟，**arm64 构建比 amd64 慢好几倍**，很容易吃掉免费额度。
- 建议：**日常只出 amd64**；确实要 arm64 时，用 GitHub Actions（公开仓库分钟数无限）或用 Oracle 的 ARM 机器原生编译。
- 阿里云 ACR 个人版不支持多架构构建（企业版才支持），但**不影响**你在 CI 里用 buildx 构建后推送镜像清单。

## 六、几条避坑提醒

1. **代码合规**：国企/涉密场景优先国内平台 + 私有仓库（CNB 私有仓库、Gitee 私有仓库、腾讯云 TCR），避免源码出境。
2. **免费额度月底清零**，不累计。
3. **信用卡不等于不扣费**：Oracle/AWS/GCP 验证不扣款，但升级付费项目后会产生费用，建议设账单告警。
4. **试用到期自动转付费**：国内云试用领取当天就设提醒，提前 7 天备份迁移。
5. **闲置回收**：几乎所有「永久免费」都会回收长期闲置实例，跑个 cron 心跳。
6. **数据备份**：免费资源随时可能回收，镜像至少保留一份 Dockerfile + 构建脚本，随时能在别处重建。
